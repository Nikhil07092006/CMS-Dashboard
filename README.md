# Modern CMS Dashboard

A simple and modern **Content Management System (CMS) dashboard** built with **HTML, CSS, and JavaScript**.
This project provides a responsive, interactive dashboard for managing content, media, contact information, and live preview.

---
🌐 **Live Demo**: [GitHub Pages Link]()
## 🚀 Features

* **Dashboard Overview** – Quick stats for media, content, contacts, and performance.
* **Content Editor** – Create and edit articles with a formatting toolbar.
* **Media Manager** – Upload and manage images via drag-and-drop or file picker.
* **Contact Information** – Update company details, business hours, and social links.
* **Live Preview** – Instantly preview changes before publishing.
* **Responsive Design** – Works across desktops, tablets, and mobiles.


3. Open `index.html` in your browser.
